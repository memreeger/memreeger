## Featured Projects

### Supplog — Supplement, Medicine & Reminder Tracking Platform

**Java · Spring Boot · Spring Security · JWT · JPA/Hibernate · PostgreSQL · React · TypeScript**

A full-stack platform for securely managing supplements, medicines, vitamins and personal reminders.

- Layered Controller, Service and Repository architecture
- DTO-based request and response models
- JWT authentication and role-based authorization
- Validation, global exception handling and i18n
- Soft deletion and user-owned data protection

🔗 [View Repository](SUPPLOG_REPOSITORY_URL)

### Arcane Game — Persistent Java Card Game Engine

**Java · PostgreSQL · JDBC · OOP · SOLID · DAO/DTO · Design Patterns**

A stateful four-round card game with user registration, authentication, difficulty levels and rule-driven scoring.

- Three 40-card decks modelled with enums and `EnumSet`
- Factory and Singleton design patterns
- Layered Model, DAO, DTO, Service and Presentation structure
- Persistent decks, hands, rounds and scores using JDBC prepared statements
- Support for resuming interrupted games

🔗 [View Repository](ARCANE_GAME_REPOSITORY_URL)

### NORA Shop — E-Commerce Application

**React · TypeScript · Firebase · Context API · React Hook Form · Zod · Tailwind CSS · i18n**

A responsive and multilingual e-commerce application with authentication and user-specific data persistence.

- Guest and authenticated shopping flows
- Cart and favourites synchronization with Firebase
- URL-based filtering and pagination
- Form validation and checkout interfaces
- Dark/light theme and multilingual support
